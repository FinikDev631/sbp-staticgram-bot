# ⚡️ СБП Stars Bot для StaticGram

Официальный Telegram / StaticGram бот **Системы Быстрых Платежей (СБП)** для мгновенных переводов звёзд (**Telegram Stars / XTR**), чеков в чатах, пополнений и прямого вывода звёзд на аккаунт.

Бот разработан 1 в 1 как реальный СБП: с аутентичными банковскими квитанциями, номерами счетов `СБП-XXXX-XXXX`, номерами транзакций `SBP-TRX-...`, нулевой комиссией (0%), экранами подтверждения и пуш-уведомлениями.

---

## 🌟 Вывод звёзд через `withdrawStarBalance`

Вывод звёзд в боте реализован в строгом соответствии с официальной документацией [docs.staticgram.top/methods/withdrawStarBalance](https://docs.staticgram.top/methods/withdrawStarBalance):

### Метод StaticGram Bot API: `withdrawStarBalance`
```http
POST https://api.staticgram.top/bot<TOKEN>/withdrawStarBalance
Content-Type: application/json

{
  "user_id": 123456789,
  "star_count": 25,
  "request_id": "wd123456789_a9b1c2d3e4f5"
}
```

### Параметры:
- `user_id`: ID пользователя или `@username` получателя.
- `star_count`: количество звёзд для вывода (от 1 ⭐️).
- `request_id`: уникальный ключ идемпотентности (до 40 ASCII-символов).

### Механика работы:
1. Пользователь нажимает **«📤 Вывести звёзды»** (`/withdraw`).
2. Выбирает получателя: **свой аккаунт** или **другого пользователя** (`@username` или Telegram ID).
3. Указывает сумму вывода (кнопками `5`, `10`, `25`, `50`, `100`, `Вывести всё` или вводом суммы).
4. Проверяет реквизиты на экране подтверждения СБП и подтверждает перевод.
5. Бот отправляет запрос `withdrawStarBalance` в StaticGram API.
6. Сервис StaticGram моментально зачисляет звёзды на баланс аккаунта получателя и присылает официальное сервисное сообщение от **777000**:
   > *«Вывод от бота @sbpbot в размере X ⭐️ зачислен на ваш баланс.»*
7. Пользователь в боте получает электронный чек об успешном исполнении вывода.

## 🚀 Основные возможности СБП

1. **⚡️ Мгновенный перевод по СБП (`/pay`):**
   - Перевод по **`@username`**, **Telegram ID** или **номеру счёта СБП**.
   - Проверка реквизитов и маскировка имени получателя (например, *Иван И.*).
   - Экран подтверждения с деталями перевода, банком и 0% комиссией.
   - Электронный чек СБП и пуш-уведомление получателю.
   - Если получатель ещё не запускал бота, звёзды резервируются и мгновенно начисляются ему при первом входе!

2. **🧾 Чеки СБП и Инлайн-переводы в чатах (`/cheque` и `@sbpbot`):**
   - Создание чеков на любую сумму (для всех участников чата или персонально под `@username`).
   - Кнопка **«🚀 Отправить чек в чат»** через инлайн-режим.
   - В чате участник нажимает `[ ⚡️ Забрать перевод (10 ⭐️) ]` — звёзды моментально зачисляются на счёт, а карточка чека обновляется!
   - Инлайн-счета: ввод `@sbpbot bill 50` в любом чате выставляет счёт СБП, который любой участник может оплатить в 1 клик.

3. **📥 Пополнение счёта звёздами (`/deposit`):**
   - Официальное выставление инвойсов `sendInvoice` в валюте `XTR`.
   - Быстрый выбор сумм: 10, 25, 50, 100, 250, 500 ⭐️ или произвольная сумма.
   - Моментальная обработка `pre_checkout_query` и `successful_payment`.
   - Зачисление на баланс СБП и электронный чек пополнения.

4. **📤 Вывод звёзд на аккаунт (`/withdraw`):**
   - Прямой вывод на баланс аккаунта через `withdrawStarBalance` себе или другому пользователю.
   - 0% комиссия сервиса, нативное зачисление от 777000.

5. **📊 Выписка и электронные чеки (`/history`):**
   - Полная история входящих/исходящих переводов, пополнений и выводов.
   - Просмотр детального электронного чека СБП по любой транзакции.

6. **🏦 Панель управления банком (`/admin`, `/bank`):**
   - Текущий резерв звёзд бота (`getMyStarBalance`).
   - Статистика пользователей, объёма и количества транзакций.
   - Вывод резерва звёзд бота владельцу в 1 клик.

## 🛠 Установка и запуск

Бот написан на **Python 3.12** с использованием современного асинхронного фреймворка **aiogram 3** и **aiosqlite**.

### 1. Настройка переменных (`.env`)
Файл `.env` уже сконфигурирован:
```env
BOT_TOKEN=1780245321:-vs-9wjhoEh9yBxCH36wfnZBcNbaC6GY6ZY
API_BASE_URL=https://api.staticgram.top
ADMIN_ID=0
```

### 2. Запуск на сервере (Хостинге)
```bash
# Установка зависимостей
pip install -r requirements.txt

# Прямой запуск
python main.py
```

#### Запуск в фоне через systemd (Linux VPS):
Создайте `/etc/systemd/system/sbpbot.service`:
```ini
[Unit]
Description=SBP StaticGram Stars Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/path/to/sbp-staticgram-bot
ExecStart=/usr/bin/python3 main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
Затем активируйте службу:
```bash
systemctl daemon-reload
systemctl enable sbpbot
systemctl start sbpbot
```

## ⚙️ Включение Инлайн-режима в @BotFather

Чтобы пользователи могли отправлять чеки прямо в чаты и выставлять счета через `@sbpbot`:
1. Откройте **@BotFather** в StaticGram.
2. Отправьте `/setinline`.
3. Выберите `@sbpbot`.
4. Введите подсказку (плейсхолдер): `Сумма перевода в ⭐️ (например, 10)`.
5. Готово! Инлайн-режим активирован.
